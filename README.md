# 🧬 GutDigest - Medical Physiology Simulation

An interactive educational game for digestive physiology learning.

## 🎮 Live Demo
[Play Now](https://your-github-username.github.io/gutdigest/)

## ✅ **EXISTING USERS:**
**Your accounts and progress are preserved!** Just login with your existing email and password.

## 🚀 Features
- 3 stages of digestive physiology simulation
- User accounts with email verification
- Cloud save across devices
- QR code verification of results
- Real-time global statistics
- Admin dashboard for educators

## 👥 For Players
1. Login with existing account OR create new account
2. Verify your email (check spam folder)
3. Play through 3 stages of digestion
4. Submit results for verification
5. Share QR codes for proof of completion

## 🔐 Admin Access
- Press **A + D keys simultaneously** to show admin button
- Click admin button and enter password: `GutDigestAdmin2025`
- Export all user data to CSV

## 📊 For Educators
- Track student progress
- Export data to CSV
- Verify student submissions via QR codes
- Real-time statistics dashboard
